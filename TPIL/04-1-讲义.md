## 1. 本课要做什么

第 3 章你学的都是**没有变量的命题**：`p ∧ q`、`p → q`、`p ∨ ¬p`——那里的 `p q` 是**固定的**命题。

第 4 章要引入**变量**：

```
∀ x : α, p x            「对每一个 x，p x 成立」
```

**本课只做一件事**：把这句话和**你已经会的东西**接上。

> ## ⭐ 全称量词**不是**新东西
> **`∀ x : α, p x` 就是 `(x : α) → p x`——一个函数类型。**
> 你在 2-2、2-9 已经学过依赖函数类型了。**本课只是告诉你：它还有一个名字叫「全称量词」。**

---

## 2. 先认识「谓词」

在讲 `∀` 之前，先看清一个类型：

```lean
example : Prop := True
```

```lean
example (α : Type) (p : α → Prop) : α → Prop := p
```

`p : α → Prop` 是什么？**它是「吃一个 `α`、吐一个命题」的函数。**

| 写法 | 读作 |
|---|---|
| `p : α → Prop` | `p` 是 `α` 上的**一元谓词** |
| `p x : Prop` | 「**`x` 满足 `p`**」这句话（一个命题） |
| `r : α → α → Prop` | `r` 是 `α` 上的**二元关系** |
| `r x y : Prop` | 「**`x` 与 `y` 有关系 `r`**」这句话 |

**例子**：若 `α = Nat`，
- `fun n => n < 5` 是一个谓词（哪些自然数小于 5）
- `fun m n => m < n` 是一个二元关系

---

## 3. ⭐ 全称量词就是函数类型

现在可以写 `∀` 了：

```lean
example (α : Type) (p : α → Prop) : Prop := ∀ x : α, p x
```

**这两行说的是同一个类型**：

```lean
example (α : Type) (p : α → Prop) : Prop := (x : α) → p x
```

```lean
-- 实测：两者可以互相直接赋值（定义上相等）
example (α : Type) (p : α → Prop) (h : ∀ x : α, p x) : (x : α) → p x := h
example (α : Type) (p : α → Prop) (h : (x : α) → p x) : ∀ y : α, p y := h
```

> **结论**：`∀` 和 `→`（依赖版）**是同一个类型构造子的两种写法**。
> - `(x : α) → β x` —— 编程视角（依赖函数）
> - `∀ x : α, β x` —— 逻辑视角（对每个 `x` 都成立）
>
> 就像 `p → q` 和「`p` 蕴含 `q`」也是同一个东西的两种读法（3-1 讲过）。

---

## 4. 怎么**证**一个 `∀`：写一个 `fun`

既然 `∀` 是函数类型，证它的办法就是**写函数**——用 `fun`：

```lean
example (α : Type) (p : α → Prop) (hp : ∀ x : α, p x) : ∀ x : α, p x :=
  fun x => hp x
```

**读法**：

```
要证  ∀ x : α, p x
   →  取一个【任意】的 x（写 fun x => …）
       此时 x : α 就在手上
       要交出 p x
```

> **逻辑上这叫「引入规则」（introduction rule）**：
> **「在一个 `x : α` 是任意的情况下证出了 `p x`，就得到了 `∀ x : α, p x`。」**
>
> 注意 `fun x => …` 里的 `x` 是**任何** `α` 的元素——你**不能对它做任何假设**，
> 也不能挑一个特定的值。这是「任意」的形式化。

---

## 5. 怎么**用**一个 `∀`：把它应用到一个值

反过来，手上有一个 `∀`，想拿到某个**具体**的 `x` 的性质——**直接应用**：

```lean
example (α : Type) (p : α → Prop) (hp : ∀ x : α, p x) (a : α) : p a :=
  hp a
```

**读法**：

```
手上有  hp : ∀ x : α, p x        （对每个 x 都成立）
手上还有 a : α                    （一个具体的元素）
   →  hp a : p a                  （把 a 代进去）
```

> **逻辑上这叫「消去规则」（elimination rule）**：
> **「有了 `∀ x : α, p x` 和任意一个 `t : α`，就得到了 `p t`。」**
>
> 这和 2-4 学的「**函数应用**」是**同一个动作**。

---

## 6. ⚠️ 作用域：`∀` 会尽量往右吃

`∀` 的**作用域尽可能宽**——它会一路向右吃到底。所以**想限制它，就得加括号**：

```lean
-- 这两行【不是】同一个命题
example (α : Type) (p q : α → Prop) : Prop := ∀ x : α, p x → q x
example (α : Type) (p q : α → Prop) : Prop := (∀ x : α, p x) → (∀ x : α, q x)
```

| 写法 | 读作 |
|---|---|
| `∀ x, p x → q x` | 「**对每个 `x`**，如果 `p x` 那么 `q x`」——`∀` 吃掉了整个 `p x → q x` |
| `(∀ x, p x) → (∀ x, q x)` | 「如果 `p` **对每个 `x`** 都成立，那么 `q` **对每个 `x`** 都成立」 |

> **记法**：**`∀` 是「贪吃」的**——它右边的**整个表达式**都在它的作用域内。
> 想让某个 `→` 在**外面**，就必须用括号把 `∀` 关起来。

---

## 7. 换个名字不影响

下面的 `x` 和 `y` 是同一个意思：

```lean
example (α : Type) (p : α → Prop) (h : ∀ x : α, p x) : ∀ y : α, p y :=
  fun y => h y
```

> **绑定变量的名字不重要**——`∀ x, p x` 与 `∀ y, p y` 是**同一个命题**。
> （这叫 **α-等价**。3-1 讲 `fun` 时也是同一个道理。）
>
> ⚠️ 但**自由变量**的名字是重要的：`p x` 里的 `p` 和你改名的 `x` 不是一回事。

## 8. 一个完整例子，逐行拆

**目标**：`(∀ x : α, p x ∧ q x) → ∀ y : α, p y`

```lean
example (α : Type) (p q : α → Prop) :
    (∀ x : α, p x ∧ q x) → ∀ y : α, p y :=
  fun h : ∀ x : α, p x ∧ q x =>
  fun y : α =>
  show p y from (h y).left
```

**逐行**：

| 行 | 手上有什么 | 要交出什么 | 做了什么 |
|---|---|---|---|
| `fun h : ∀ x, p x ∧ q x =>` | — | `∀ y, p y` | 最外层是 `→`，**收下左边**（3-2 的动作） |
| `fun y : α =>` | `h : ∀ x, p x ∧ q x` | `p y` | 要证 `∀ y, p y` → **取一个任意的 `y`**（本课的新动作） |
| `show p y from (h y).left` | 还有 `y : α` | `p y` | **消去**：`h y : p y ∧ q y`，取 `.left` 得 `p y` |

**一句话**：**引入（`fun y`）→ 消去（`h y`）→ 取左边**。

## 📎 附：本课新出现的符号

| 符号 | 怎么打 | 含义 |
|---|---|---|
| `∀` | `forall` 或 `\forall` | 全称量词 |
| `∀ x : α, p x` | — | 对每个 `x : α`，`p x` 成立 |
| `(x : α) → p x` | — | 与上面那行的 `∀ x : α, p x` 是**同一个类型** |
| `α → Prop` | — | `α` 上的一元谓词 |
