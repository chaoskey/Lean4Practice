## 检查命令（备用，等有 .lean 习题时再用）

```bash
export PATH="$HOME/.elan/bin:$PATH"
lake env lean TPIL/02-1-习题.lean        # 逐文件检查（把文件名换成当前的）
```

**⚠️ 注意 `sorry` 的陷阱**：`sorry` 只是 **warning**，退出码仍是 **0**。
「能通过检查」**不代表**题都做完了。

真正的验收（两条都要过）：

```bash
export PATH="$HOME/.elan/bin:$PATH"
lake env lean TPIL/02-1-习题.lean && ! grep -qE '^[[:space:]]*sorry[[:space:]]*$' TPIL/02-1-习题.lean
```

即 **① 无编译错误 ② 文件里不再有「整行就是 `sorry`」的占位**。

> ⚠️ 别用 `grep -n 'sorry'` 这种简单写法——它会把**注释里提到 `sorry` 的文字**也算作占位。
