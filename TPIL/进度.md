- 第 6 题第 3 项：`Nat.succ` 名字里带 `Nat.`（命名空间），**看着像类型名**，就判成了类型。
  实际上它是 `Nat` 这个类型的**构造子**，是一个**函数值**，类型为 `Nat → Nat`。
- 第 7 题：`Nat.add 3` 的**类型**是 `Nat → Nat`，看到箭头就以为「它是类型」。
  实际上「**它的类型是函数类型**」≠「**它是类型**」。

**已发给用户的判据**（用与习题不同的例子演示，不代做）：

```
#check X   →  看冒号【右边】那串：
   右边是 Type      → X 是类型
   右边是别的东西    → X 是值（右边那串就是它的类型）
```

| 实测 | 冒号右边 | 判定 |
|---|---|---|
| `Bool.true : Bool` | `Bool` | 值 |
| `Nat.pred : Nat → Nat` | `Nat → Nat` | 值 |
| `Nat.add 2 : Nat → Nat` | `Nat → Nat` | 值 |
| `Nat → Nat : Type` | `Type` | **类型** |

> 关键对照：**同一串 `Nat → Nat`，位置决定角色**——站在 `#check` 输出的**右边**时，
> 它只是「左边那个东西的类型」；**被拿去问**（`#check (Nat → Nat)`）时，它自己才是类型。
