## 如何检查你的作答

**逐文件检查**（习题不属于构建库，所以 `lake build` 不会连带检查它们）：

```bash
export PATH="$HOME/.elan/bin:$PATH"
lake env lean TPIL/03-习题.lean
```

**⚠️ 注意 `sorry` 的陷阱**：`sorry` 只是 **warning**，退出码仍是 **0**。
所以「能通过检查」**不代表**题都做完了——空壳答案一样能通过。

**真正的验收**（两道都得过）：

```bash
export PATH="$HOME/.elan/bin:$PATH"
lake env lean TPIL/03-习题.lean && ! grep -qE '^[[:space:]]*sorry[[:space:]]*$' TPIL/03-习题.lean
```

即：**① 无编译错误 ② 文件里不再有「整行就是 `sorry`」的占位**。

> ⚠️ **别用 `grep -n 'sorry'` 这种简单写法**——它会把**注释里提到 `sorry` 的文字**也算作占位，导致你做完了却显示「未通过」。必须用上面这条「整行匹配」。
