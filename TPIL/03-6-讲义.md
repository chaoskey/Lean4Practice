# 第 3 章 · 第 6 课：逻辑等价 `↔`

> 📄 **示例**：`03-6-示例.lean`（我写的，已通过编译、零 warning）
> ✍️ **习题**：`03-6-习题.lean`（**你写**）
> 📖 **原文**：<https://lean-lang.org/theorem_proving_in_lean4/Propositions-and-Proofs/#logical-equivalence> 的 **3.3.4「Logical Equivalence」**（我用中文讲透）
> 🔤 **打不出符号时**：`↔` 写成 `Iff` 就行（见 [`Unicode速查.md`](./Unicode速查.md)）
> **本课的一句话**：**`p ↔ q`（读作「`p` 当且仅当 `q`」）= 两个方向都要证**——既要证 `p → q`，又要证 `q → p`；而 Lean 把这两个方向**打包成一件东西**，于是你一次就把两段证明交上去。

---

## 1. 定位：第五个连接词

| 已学 | 造它 | 用它 |
|---|---|---|
| `→`（3-2） | `fun hp : p => …` | `hf hp` |
| `∧`（3-3） | `⟨hp, hq⟩` | `.left` / `.right` |
| `∨`（3-4） | `Or.inl` / `Or.inr` | `Or.elim` |
| `¬`（3-5） | `fun hp : p => …` | `False.elim` / `absurd` |
| **`↔`（本课）** | **`⟨h₁, h₂⟩`（两个方向）** | **`.mp`（正向） / `.mpr`（反向）** |

⚠️ **先分清两个不同的「等价」**：

1. **本课的 `↔`**：**两个命题**之间的「当且仅当」（`p ↔ q`）；
2. **按定义相等**：两个**类型**是同一个东西——你在 3-2 前后和 3-5 已经用过它（`¬p` 与 `p → False` 就是这一种）。

**这两件事长得像，但不是一回事**——§4 专门讲这件事。

---

## 2. `Iff` 长什么样

`↔` 背后的类型叫 **`Iff`**（读作「**if and only if**」，等价于英文的 **iff**）。实测：

```lean
#check Iff
#print Iff
```

实测输出：

```
Iff (a b : Prop) : Prop
structure Iff (a b : Prop) : Prop
number of parameters: 2
fields:
  Iff.mp : a → b
  Iff.mpr : b → a
constructor:
  Iff.intro {a b : Prop} (mp : a → b) (mpr : b → a) : a ↔ b
```

**逐行读**（对照 3-3 讲的 `structure And`，它们是**同一类东西**）：

| 这行 | 意思 |
|---|---|
| `structure Iff (a b : Prop) : Prop` | `Iff` 是个 **structure（结构）**，吃两个命题、产出一个命题 |
| `fields:` 下面两行 | 它**有且仅有两条内容**：`mp`（正向：拿 `a` 换 `b`）和 `mpr`（反向：拿 `b` 换 `a`） |
| `constructor:` 后面**只有一个** | `Iff.intro`，**吃两样**：一个 `a → b`、一个 `b → a` |

**mp / mpr 这两个名字从哪来**：**m**o**p**（modus ponens，「肯定前件」，就是「有 `p` 就有 `q`」）和 **m**o**dus **t**o**r**ens（「否定后件」，「有 `q` 就有 `p`」）。**记住它们是「两条方向」就够了**。

## 3. 造一个 `p ↔ q`：两个方向都要交

`Iff.intro` 的类型（实测）：

```lean
#check Iff.intro
```

```
Iff.intro {a b : Prop} (mp : a → b) (mpr : b → a) : a ↔ b
```

**两个显式参数**，顺序是**正向在前、反向在后**。⚠️ **它只接受一个构造子**（§2 最后一行），所以 **`⟨,⟩` 可用**——和 3-3 的 `And` 一样（和 3-4 的 `Or` 不一样，`Or` 有两个构造子）。

原文的例子（合取的交换律）：

```lean
variable (p q : Prop)

theorem and_swap : p ∧ q ↔ q ∧ p :=
  Iff.intro
    (fun h : p ∧ q => show q ∧ p from And.intro (And.right h) (And.left h))
    (fun h : q ∧ p => show p ∧ q from And.intro (And.right h) (And.left h))
```

**逐行拆**（`show … from` 是 3-2 学的）：

| 这一行 | 在干什么 |
|---|---|
| `Iff.intro` | 「我要交一个等价」 |
| 第 1 个参数 `fun h : p ∧ q => …` | **正向 `p ∧ q → q ∧ p`**：接住一个对，把 `q` 放左边、`p` 放右边（`.right` / `.left`，3-3 学的） |
| 第 2 个参数 `fun h : q ∧ p => …` | **反向 `q ∧ p → p ∧ q`**：接住对调过的对，**放回原样**（**注意这里也用 `.right` / `.left`**——因为手上的东西也是「对调过的那个对」） |

**用 `⟨,⟩` 写同一件事**（更短，实测通过）：

```lean
variable (p q : Prop)

theorem and_swap2 : p ∧ q ↔ q ∧ p :=
  ⟨ fun h => ⟨h.right, h.left⟩, fun h => ⟨h.right, h.left⟩ ⟩
```

## 4. ⚠️ `p ↔ q` **不是** `(p → q) ∧ (q → p)` 的别名

这是本课**最容易被误解**的一点，**实测如下**：

```lean
variable (p q : Prop)

-- ❌ 这句**不通过**（所以「二者按定义相等」是错的）
-- example (h : p ↔ q) : (p → q) ∧ (q → p) := h
```

而**要写出来**，得用两条实测都通过的写法：

```lean
variable (p q : Prop)

-- ✅ 从「等价」造出「一对方向」
example (h : p ↔ q) : (p → q) ∧ (q → p) := ⟨h.mp, h.mpr⟩
-- ✅ 从「一对方向」造出「等价」
example (h : (p → q) ∧ (q → p)) : p ↔ q := Iff.intro h.left h.right
```

**为什么**：`Iff` 是个 **structure**（§2），它**自己就是那两条方向的容器**；它**不是** `And`。**两条要互相转换，不能直接顶替。**

⚠️ **和 3-5 的 `¬p` 对照着记**（这是本课最值得带走的一组对比）：

| | 背后是什么 | 是不是别名 |
|---|---|---|
| `¬p` | `def`（一个缩写） | ✅ **`¬p` 与 `p → False` 按定义相等**（3-5 实测两个方向都过） |
| **`p ↔ q`** | **`structure Iff`** | ❌ **与 `(p → q) ∧ (q → p)` 不是同一个类型**（§4 实测报错） |

**为什么 Lean 要这样设计**：`And` 有一个通用的消法（`.left` / `.right`），而「等价」需要的是**另一套**（`.mp` / `.mpr`）；`Iff` 正好是**专门**为这两个方向设计的类型。

## 5. 用它：把一个方向取出来

`Iff.mp` / `Iff.mpr` 的类型（实测）：

```lean
#check Iff.mp
#check Iff.mpr
```

```
Iff.mp {a b : Prop} (self : a ↔ b) : a → b
Iff.mpr {a b : Prop} (self : a ↔ b) : b → a
```

| | 类型 | 干什么 |
|---|---|---|
| `Iff.mp` | `(a ↔ b) → a → b` | 手上有一个「等价」，**要正向** |
| `Iff.mpr` | `(a ↔ b) → b → a` | 手上有一个「等价」，**要反向** |

**两种取法**（实测都通过）：

```lean
variable (p q : Prop)

theorem and_swap3 : p ∧ q ↔ q ∧ p :=
  ⟨ fun h => ⟨h.right, h.left⟩, fun h => ⟨h.right, h.left⟩ ⟩

-- ① 点记号（推荐）
example (h : p ∧ q) : q ∧ p := (and_swap3 p q).mp h
-- ② 全名调用
example (h : p ∧ q) : q ∧ p := Iff.mp (and_swap3 p q) h
```

⚠️ **哪些记号可用、哪些不行**（**全部实测**）：`h.mp` ✅、`h.mpr` ✅、**`h.1`** ✅、`h.2` ✅；但 **`h.left` ❌**（`Iff` 没有叫 `left` 的字段——`And` 才有）、**`h.1.mp` ❌**（`h.1` 是**函数**，不是结构，不能再点）。

## 6. ⚠️ 优先级与结合性（**实测结论与原文不同**）

`↔` 的优先级**比 `→` 松**，也就是 `→` **先**结合。三条实测：

```lean
variable (p q r : Prop)

#check (p ↔ (q ↔ r))
-- p ↔ (q ↔ r) : Prop   ✅ 括号版当然可以
#check ((p ↔ q) ↔ r)
-- (p ↔ q) ↔ r : Prop   ✅
```

而 `#check (p ↔ q ↔ r)` **报错**（**故意写错，所以这里用普通代码块**）：

```
error: unexpected token '↔'; expected ')', ','
```

**规律**：

1. **括号该加还是要加**：`p ↔ (q ↔ r)` 与 `(p ↔ q) ↔ r` 都是合法的类型；
2. ⚠️ **`↔` 不能连写**——`p ↔ q ↔ r` **语法错**，**必须**自己加括号。

**顺带实测一下 `↔` 与 `→` 谁先结合**（用「只能有一种结合才写得出来」的句子来判断）：

```lean
variable (p q r : Prop)

#check (p ↔ q → r)
-- 能通过，说明它读作 p ↔ (q → r)
#check (p → q ↔ r)
```

`p → q ↔ r` 这条**能通过**，但**只表示 `p → q` 和 `r` 之间有个 `↔`**（即 `(p → q) ↔ r`）；**要表达「`p` 蕴含『`q` 等价于 `r`』」，必须写 `p → (q ↔ r)`**。**一句话**：**`→` 比 `↔` 结合得早**，所以**含 `↔` 的 `→` 一定加括号**。

> 📌 原文在这一节写的是「**`↔` 是右结合的**」；**实测 v4.34.0 上 `p ↔ q ↔ r` 是语法错**——以**实测**为准（和 3-5 那些实测结论一样）。

## 7. 五个连接词总表

| | 读作 | 造它 | 用它 | 构造子个数 |
|---|---|---|---|---|
| `p → q` | 若 `p` 则 `q` | `fun hp : p => …` | `hf hp` | —— |
| `p ∧ q` | 并且 | `⟨hp, hq⟩` | `.left` / `.right` | 1 |
| `p ∨ q` | 或 | `Or.inl` / `Or.inr` | `Or.elim` | 2 |
| `¬p` | 非 `p` | `fun hp : p => …` | `False.elim` / `absurd` | 0（`False`） |
| **`p ↔ q`** | **当且仅当** | **`⟨h₁, h₂⟩`（两方向）** | **`.mp` / `.mpr`** | **1（`Iff`）** |

## 9. 小结

1. **`p ↔ q` = 两个方向都要**（正向 `p → q` + 反向 `q → p`），所以**一次要交两个证明**；
2. **`Iff` 是 `structure`**、**只有 1 个构造子** `Iff.intro`（两个参数：正向在前、反向在后）→ **`⟨,⟩` 可用**；
3. ⚠️ **`p ↔ q` 与 `(p → q) ∧ (q → p)` 不是同一个类型**（实测报错）——**这一点和 `¬p` 与 `p → False`（按定义相等）正好相反**；
4. **取方向**：`h.mp`（正向）/ `h.mpr`（反向）；`h.1` / `h.2` 也行；**`h.left` 不行**；
5. ⚠️ **优先级**：`→` 比 `↔` 结合得早，**含 `↔` 的 `→` 要加括号**；**`↔` 不能连写**（原文说右结合，实测是语法错）。
