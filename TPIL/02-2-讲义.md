# 第 2 章 · 第 2 课：从已有类型造新类型（`→` 和 `×`）

> 📄 **示例**：`02-2-示例.lean`（我写的，已通过编译、零 warning）
> ✍️ **习题**：`02-2-习题.lean`（**你写**）
> 本课只讲一件事：**类型不是天生就那么多，你可以用已有类型造出新类型。**

---

## 1. 本课的一句话

上一课我们知道：每个表达式都有类型。

这一课要知道：**类型本身也可以「造」出来**。

教材原话说得好——「简单类型论之所以强大，就在于你可以**从别的类型造出新类型**」。这正是它比"把 `Nat`、`Bool` 当固定清单"要强的地方。

本课学**两种**造法：

| 造法 | 写法 | 读作 |
|---|---|---|
| 函数类型 | `a → b` | 「从 a 到 b 的函数」这个类型 |
| 对（笛卡尔积） | `a × b` | 「一个 a 和一个 b 组成的二元组」这个类型 |

---

## 2. 函数类型：`a → b`

如果 `a` 和 `b` 都是类型，那么 `a → b` **也是一个类型**——它表示「输入 a、输出 b 的函数」这一整类东西。

```lean
#check Nat → Nat        -- Nat → Nat : Type
#check Bool → Nat       -- Bool → Nat : Type
```

注意输出最后是 `: Type`——说明 **`Nat → Nat` 本身是个类型**，不是值。

### 怎么打出箭头 `→`

| 你想输入 | 打什么 |
|---|---|
| `→` | `\to` 或 `\r` 或 `\->` |
| `→` 的 ASCII 替代 | 直接打 `->` |

`Nat -> Nat` 和 `Nat → Nat` **完全一样**，只是 `→` 更好看。

---

## 3. 对（笛卡尔积）：`a × b`

`a × b` 表示「第一个是 a、第二个是 b 的二元组」这个类型。名字叫**笛卡尔积**。

```lean
#check Nat × Nat        -- Nat × Nat : Type
#check Nat × Bool       -- Nat × Bool : Type
```

`×` 打 `\times`。（**所有符号的输入方式**——含美式键盘上的打法——见 [`Unicode速查.md`](./Unicode速查.md)。）（这是个 Unicode 符号。现代编辑器对 Unicode 支持都很好，用了可读性更高——Lean 标准库里也常见希腊字母当类型名。）

---

## 4. 写法 vs 本名：`×` 其实就是 `Prod`

上一课我们见过 `true` 的本名是 `Bool.true`。这里**同一个现象再出现一次**：

```lean
#check Prod Nat Nat     -- Nat × Nat : Type
```

**你输入 `Prod Nat Nat`，Lean 回给你 `Nat × Nat`。** 因为 `×` 只是 `Prod` 这个类型构造器的**记号**，就像 `true` 只是 `Bool.true` 的记号。

**记住这个规律**：Lean 有时会把你的写法换成它的「本名」，有时反过来换成更好看的「记号」。**看到不认识的写法时，先想它是不是某个你熟悉的东西的另一种写法。**

---

## 5. 箭头是「右结合」的

这是个读代码必须知道的规则：

```
Nat → Nat → Nat      实际是      Nat → (Nat → Nat)
```

也就是：**箭头从右往左结合**。所以 `Nat → Nat → Nat` 的意思是「吃一个 `Nat`，吐出一个**函数**（`Nat → Nat`）」。

Lean 实测能看出来——我这里**故意打了括号**，Lean 把括号去掉了：

```lean
#check Nat → Nat → Nat      -- Nat → Nat → Nat : Type
#check Nat → (Nat → Nat)    -- Nat → Nat → Nat : Type   ← 括号消失
```

两行输出一模一样，说明它们**本来就是同一个类型**（括号是多余的）。

---

## 6. 部分应用：喂一半参数，得到一个函数

既然 `Nat → Nat → Nat` 是「吃一个 Nat，吐一个函数」，那么——

**喂它一个参数，剩下的正是一个函数。**

```lean
#check Nat.add          -- Nat.add : Nat → Nat → Nat   （吃两个）
#check Nat.add 3        -- Nat.add 3 : Nat → Nat       （吃一个了）
#eval Nat.add 5 2       -- 7                            （喂两个，出结果）
```

这不是什么特殊功能，而是上面「右结合」的**直接后果**。后面写证明时会经常用到。

---

## 7. 对的值：怎么造、怎么取

类型有了，还要有**值**。

```lean
#check (5, 9)           -- (5, 9) : Nat × Nat   ← 用括号造一个对
#eval (5, 9).1          -- 5                     ← .1 取第一个
#eval (5, 9).2          -- 9                     ← .2 取第二个
#check (5, 9).fst       -- (5, 9).fst : Nat      ← .fst 和 .1 是同一个东西
```

### ⚠️ 这里有两个容易卡住的地方

**第一个：`#check` 问的是「类型」，只有 `#eval` 才会给你「值」。**

| 你写的命令 | 问的是什么 | 得到的回答 | 是什么东西 |
|---|---|---|---|
| `#eval (5, 9).1` | 它的**值** | `5` | 一个**值** |
| `#check (5, 9).fst` | 它的**类型** | `Nat` | 一个**类型** |

所以最后一行**不会打印出 `5`**——这不是它「不是 5」，而是**你问的问题不是「它是几」**。
两个命令问的是同一个东西的两个不同侧面：

- `(5, 9).1` 和 `(5, 9).fst` **本来就是同一个东西**（都是取出来的那个 5）；
- **问它的类型 → 回 `Nat`；问它的值 → 回 `5`。**

想把 5 打印出来，就用 `#eval`（下面两行是实测输出）：

```lean
#eval (5, 9).fst        -- 5
#eval (5, 9).snd        -- 9
```

**第二个：`.1` 和 `.fst` 是同一个东西的两种写法。**

`.1` / `.2` 只是**记号**，它们的**本名**是 `.fst` / `.snd`——正好和第 4 节里
「`×` 是本名 `Prod` 的记号」是同一个道理。Lean 打印时会顺手把记号换成本名，所以你输入
`#check (5, 9).1`，它回给你的是 `(5, 9).fst : Nat`（实测）。

一句话记住：

| 记号 | 本名 | 意思 |
|---|---|---|
| `.1` | `.fst` | 取第一个 |
| `.2` | `.snd` | 取第二个 |

**两种写法随便用，意思完全一样。**

---

## 8. 一个会让你困惑的显示差异（重要）

先看清这两行**真正**的区别在哪——它们**不是**同一个函数：

```lean
#check Nat.succ         -- Nat.succ (n : Nat) : Nat      ← 吃 1 个 Nat
#check Nat.add          -- Nat.add : Nat → Nat → Nat     ← 吃 2 个 Nat
```

`Nat.succ` 是「加一」，吃**一个** `Nat`；`Nat.add` 是「加法」，吃**两个** `Nat`。
**它们当然不一样**——光参数个数就不同。

那这一节说的「一样」是指什么？指的是**写类型时的两种排版**：

| 排版 | 长相 | 出现条件 |
|---|---|---|
| 望远镜式（带参数名） | `f (n : Nat) : Nat` | 类型里给参数**起了名字** |
| 箭头式 | `f : Nat → Nat` | 类型里的参数是**匿名的**（`_`） |

**这两种排版指的是同一个类型**——`(n : Nat) : Nat` 和 `Nat → Nat` 是一回事。
Lean 对上面两个函数用了不同排版，**只是因为它们在标准库里当初就是那么写的**，
和「意思不同」毫无关系。下面这四行是我实测的，规律一眼可见：

```lean
def a (n : Nat) : Nat := n + 1          -- #check a  →  a (n : Nat) : Nat
def b : Nat → Nat := fun n => n + 1     -- #check b  →  b : Nat → Nat
def c : (n : Nat) → Nat := fun n => n   -- #check c  →  c (n : Nat) : Nat
def g : (_ : Nat) → Nat := fun n => n   -- #check g  →  g : Nat → Nat
```

**规律：参数有名字 → 望远镜式；参数匿名（`_`）→ 箭头式。**（注意第 4 行：名字写成 `_`，Lean 就按匿名处理，显示箭头式。）

### 这两种写法确实是同一个类型（实测）

```lean
def useArrow (f : Nat → Nat) : Nat := f 3          -- 这里要的是箭头式
#eval useArrow a        -- 4     ← 望远镜式写出来的 a，照样能塞进去
#eval useArrow b        -- 4

def useNamed (f : (x : Nat) → Nat) : Nat := f 4    -- 这里要的是望远镜式
#eval useNamed a        -- 5     ← 反过来也一样
#eval useNamed b        -- 5
```

**互相能塞进去**（而且 `#eval` 算出来的结果完全一样），说明**两种写法就是同一个类型的两种拼法**。

> 注：这里本来还可以补一句 `example : a = b := rfl`，用「相等」直接判定两者是同一个函数。
> 但那要用到 `=` 与 `rfl`——**属于第 3 章《命题与证明》的内容，本课不引入**，所以这里不写。
> 上面「互相能塞进去」已经足够说明问题了。

### 还有一层：同一声明，换个命令显示也不同（实测）

```lean
#check a      -- a (n : Nat) : Nat         ← 望远镜式
#print a      -- def a : Nat → Nat := ...  ← 同一件事，箭头式
```

所以**显示形式完全不能用来推断含义**。

> 💡 **唯一该做的事：数参数个数、看参数是什么类型，就知道它吃几个、吐什么。**
> 看到 `(n : Nat) : Nat` 不要慌，那和 `Nat → Nat` 是同一句话。

## 9. ⚠️ 补一个通用判据：它是「类型」还是「值」？

> 这一节是**批改习题时补上的**——第 2 课习题里有两道预测题正是卡在这里。
> 这条判据以后**每一课都用得上**，请务必记牢。

判法很简单：用 `#check X`，看输出里**冒号右边**那一串是什么。

| 冒号右边是 | 结论 |
|---|---|
| `Type` | `X` 是**类型** |
| 别的东西（`Nat`、`Nat × Nat`、`Nat → Nat`…） | `X` 是**值**，而右边那串就是它的**类型** |

实测四个例子：

```lean
#check Bool.true        -- Bool.true : Bool         ← 右边是 Bool    → 值
#check Nat.pred         -- Nat.pred : Nat → Nat     ← 右边是箭头式   → 值！
#check Nat.add 2        -- Nat.add 2 : Nat → Nat    ← 右边是箭头式   → 值！
#check (Nat → Nat)      -- Nat → Nat : Type         ← 右边是 Type    → 类型
```

### 最容易踩的坑：同一串 `Nat → Nat`，**位置**决定角色

- 它出现在 `#check` 输出的**右边**——`Nat.add 2 : Nat → Nat`——那它只是**左边那个东西的类型**；
  左边那个东西（`Nat.add 2`）是**值**。
- 它被**拿去问**——`#check (Nat → Nat)` → `Nat → Nat : Type`——这时它自己才是**类型**。

所以两条要记住：

1. **「它的类型是函数类型」不等于「它是类型」。**
2. 名字里带 `Nat.` 只是**命名空间**，不代表它是类型。`Nat.succ` 是一个**值**（一个函数），
   它的类型才是 `Nat → Nat`。

## 10. 小结

本课记住四件事：

1. **类型可以从已有类型造出来**——这是类型论强大的根源
2. **两种造法**：`a → b`（函数）、`a × b`（对）
3. **箭头右结合**：`Nat → Nat → Nat` = `Nat → (Nat → Nat)`，由此有了**部分应用**
4. **显示形式不等于含义**：
   - `#check` 问**类型**、`#eval` 问**值**（问法不同，答案当然不同）
   - `(n : Nat) : Nat` 和 `Nat → Nat` 是**同一个类型**的两种排版
   - `.1` / `.2` 只是记号，本名是 `.fst` / `.snd`
   - 判「类型 / 值」看 `#check` 冒号右边：是 `Type` → 类型，否则是值
