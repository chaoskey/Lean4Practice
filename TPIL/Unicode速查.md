# Unicode 速查：这些符号怎么打

> **这是什么**：本项目材料里有一批**不在美式键盘上**的符号（`→`、`×`、`α`、`⟨⟩`…）。
> 本文件是**输入速查表**——**遇到打不出来的符号就来这里查**。
> **跨课通用**（不属某一课）；各课讲义在需要时会指向本文件。

---

## 1. 三条路（先看这个）

| 路 | 怎么做 | 什么时候用 |
|---|---|---|
| ① **纯 ASCII 写法** | 很多符号 Lean 也认 ASCII 写法（**§2** 列了实测过的） | **完全不想碰 Unicode** 时；在纯终端、或没装 Lean 扩展的编辑器里 |
| ② **`\` 缩写**（推荐） | 在 **VS Code + Lean 4 扩展**里打 `\to`，再按**空格**（或 Tab）→ 当场变成 `→` | 日常写代码 |
| ③ **复制粘贴** | 从材料里复制 | 零配置；偶尔用一个符号 |

⚠️ **前提（重要）**：`\` 缩写是**编辑器功能**，**不是 Lean 语言的一部分**——它由 **VS Code 的 Lean 4 扩展**提供。
纯终端里 `lake env lean` 只认**字符本身**（它不管你键盘上怎么打）。**没装扩展就用 ① 或 ③。**

## 2. 先说 ASCII 这一路：能少打很多符号（**全部实测过**）

| 想要的 | ASCII 写法 | 实测结果（`#check`） |
|---|---|---|
| `→` | `->` | `#check (Nat -> Nat)` → `Nat → Nat : Type` |
| `λ` | `fun` | `#check (fun x : Nat => x)` → `fun x => x : Nat → Nat` |
| `×` | `Prod` | `#check (Prod Nat Nat)` → `Nat × Nat : Type` |
| `⟨a, b⟩` | `Prod.mk a b` | `#check (Prod.mk 5 9)` → `(5, 9) : Nat × Nat` |
| `Σ` | `Sigma` | `#check (Sigma (fun n : Nat => Fin (n + 1)))` → `(n : Nat) × Fin (n + 1) : Type` |
| `∀` | `forall` | `#check (forall (n : Nat), n = n)` → `∀ (n : Nat), n = n : Prop` |
| `∃` | `Exists` | `#check (Exists (fun n : Nat => n = n))` → `∃ n, n = n : Prop` |
| `∧` | `/\` | `#check (True /\ True)` → `True ∧ True : Prop` |
| `∨` | `\/` | `#check (True \/ False)` → `True ∨ False : Prop` |
| `¬` | `Not` | `#check (Not True)` → `¬True : Prop` |
| `↔` | `Iff` | `#check (Iff True False)` → `True ↔ False : Prop` |
| `≠` | `Ne` | `#check (Ne 1 2)` → `1 ≠ 2 : Prop` |
| `≤` `≥` | `<=` `>=` | `#check (1 <= 2)` → `1 ≤ 2 : Prop` |
| **类型变量名** `α` `β` | **随便叫 `A` `B`** | `def consA (A : Type) (a : A) (as : List A) : List A := …` ✅ |

> ⚠️ **一个陷阱**：`!=` **不是** `≠`！`#check (1 != 2)` 得到的是 **`1 != 2 : Bool`**（布尔运算），
> 而 `≠`（`1 ≠ 2 : Prop`）要用 `Ne`。**两者完全不同**。

> ⚠️ **另一个陷阱（最容易踩，2026-09-19 当场踩到）**：**ASCII 尖括号 `<` `>` 不是 Lean 的 `⟨` `⟩`！**
> 想写 `⟨a, b⟩` 却打成 `<a, b>`，会直接报错：
> ```
> error: unexpected token '<'; expected term
> ```
> **两条修法**：① 打 `\<` + 空格 → `⟨`（`\>` → `⟩`）；② 或走 **ASCII 路线**：`Sigma.mk a b` / `Prod.mk a b`。实测两种都对：
> ```lean
> def f1 (α : Type) (β : α → Type) (a : α) (b : β a) : (a : α) × β a := ⟨a, b⟩
> def f2 (α : Type) (β : α → Type) (a : α) (b : β a) : (a : α) × β a := Sigma.mk a b
> ```

> 💡 **但注意**：Lean **打印**出来的永远是**符号版**——所以你即使全用 ASCII 写，
> **读**的时候还是得认得 `→`、`×`、`∀` 这些符号。这也是本文件存在的原因。

## 3. 符号总表（按用途分组）

> 「`\` 缩写」列里，**打任一个**再按**空格**即可。缩写**全部取自官方表**（见 §6），
> 并且生成时做过**自检**：每一条都能在官方表里查到、且值与该符号相符。

### 3.1 函数与类型（**现在就在用**）

| 符号 | `\` 缩写 | 纯 ASCII 写法 | 含义 | 什么时候遇到 |
|---|---|---|---|---|
| `→` | `\to`  `\r`  `\->` | `->` | 函数类型「吃 A、吐 B」；`(a : α) → β a` 是**依赖**版 | 2-2、2-9 |
| `←` | `\l`  `\<-`  `\l-` | — | 反向箭头（类型里很少用） | — |
| `λ` | `\lam`  `\lambda`  `\fun` | `fun` | 函数抽象——和 `fun` **完全一样** | 2-4 |
| `×` | `\times`  `\x`  `\multiplication` | `Prod` | 乘积类型（把两个类型配起来） | 2-2 |
| `Σ` | `\Sigma`  `\S`  `\GS` | `Sigma` | **依赖对**（sigma 类型） | 2-9 |
| `Π` | `\Pi`  `\P`  `\p` | — | 依赖函数类型的另一种写法（= `(a : α) → β a`） | 以后 |
| `⟨` | `\<`  `\langle` | `Prod.mk a b` / `Sigma.mk a b` | 匿名构造子：**造**一个配对 | 2-2 |
| `⟩` | `\>`  `\rangle` | （同上） | （同上） | 2-2 |
| `·` | `\.`  `\cdot`  `\dot` | （**没有** ASCII 写法） | 「聚焦点」：证明里指向当前目标 | 第 3 章 |
| `∘` | `\circ`  `\o`  `\comp` | `Function.comp` | 函数复合 `f ∘ g` | 以后 |
| `↦` | `\mapsto`  `\ma`  `\r-|` | — | 「映射到」 | 以后 |
| `↔` | `\iff`  `\lr`  `\<->` | `Iff` | 「当且仅当」 | 第 3 章 |
| `⇒` | `\=>`  `\r=`  `\Rightarrow` | — | 「推出」（Lean 里更常见 `→`） | 以后 |

## 5. 省事技巧：成对括号一次打出来

官方表里有一类「**成对**」缩写：打完按空格，会**同时插入左右两边、并把光标放在中间**：

| 打什么 | 得到 | 光标位置 |
|---|---|---|
| `\<>` | `⟨⟩` | 两个之间 |
| `\()` | `()` | 两个之间 |
| `\[]` | `[]` | 两个之间 |
| `\{}` | `{}` | 两个之间 |
| `\{{}}` | `⦃⦄` | 两个之间 |
| `\[[]]` | `⟦⟧` | 两个之间 |

**分开打**也完全可以：`\<` → `⟨`，`\>` → `⟩`。

## 7. 一句话备忘

1. **能 ASCII 就 ASCII**（§2）——`->`、`fun`、`Prod`、`A`/`B` 都行。
2. **VS Code 里用 `\` 缩写**（§3）——`\to` + 空格 = `→`。
3. **Lean 打印永远是符号版**——所以符号**得认得**，哪怕你不打它。
4. **`α`/`β` 只是名字**——随手写 `A`/`B` 完全没问题。
