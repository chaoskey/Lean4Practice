# 第 4 章 · 第 6 课：存在量词 `∃`（一）——**构造**

> **本课范围**：原文 **4.4 The Existential Quantifier** 的**前半**——「怎么**证出**一个 `∃`」。
> 后半「拿到一个 `∃` 之后怎么**用**它」（`Exists.elim`、`match`、模式匹配）是**下一课 04-7**。
>
> **本课一句话**：要证 `∃ x, p x`，你只需要交**两样东西**——一个**见证** `w` 和一份 `p w` 的证明。
>
> ⚠️ **全节 tactic 0 处**：本课**只用证明项**。

---

## §1 `∃` 到底是什么

原文第一句就把底交了：`∃` **只是一个记法**——

> `∃ x : α, p x` 是 `Exists (fun x : α => p x)` 的**方便写法**。

`Exists` 自己的类型（**实跑**）：

```lean
#check Exists
```

```
Exists.{u} {α : Sort u} (p : α → Prop) : Prop
```

读法：`Exists` 吃一个**谓词** `p : α → Prop`，吐出一个**命题**。
所以 `∃` 不是「一个新逻辑符号」，而是**把「存在某个 `x` 使 `p x`」编码成了「谓词 `Exists` 成立」**。

**实测：两种写法真的是同一个东西**（`rfl` 直接能证）：

```lean
section exists_notation
example (α : Type) (p : α → Prop) : (∃ x, p x) = Exists (fun x => p x) := rfl
end exists_notation
```

> 📌 这又是本课程的老套路：**新记法 = 旧东西的写法**（`∃` ↔ `Exists`，就像 `▸` ↔ `Eq.rec`、`calc` ↔ `trans`）。

---

## §2 构造规则：`Exists.intro`

原文说，库里有**引入规则**（introduction rule）和**消去规则**（elimination rule）。本课只讲**引入**：

> 要证 `∃ x : α, p x`，**交一个合适的项 `t`** 和 **`p t` 的证明**就够了。

它的完整类型（**实跑**）：

```lean
#check @Exists.intro
```

```
@Exists.intro : ∀ {α : Sort u_1} {p : α → Prop} (w : α), p w → Exists p
```

逐段读：

| 部分 | 是什么 | 谁提供 |
|---|---|---|
| `{α : Sort u_1}` | 元素的类型 | **隐式**——从上下文推 |
| `{p : α → Prop}` | 那个谓词 | **隐式**——从上下文推（⚠️ 见 §5，这是本课最容易出事的地方） |
| `(w : α)` | **见证**（witness） | **你交** |
| `p w` | 「见证确实满足谓词」的**证明** | **你交** |
| `Exists p` | 结论：`∃ x, p x` | 自动 |

所以：**证明一个 `∃` 就是「人赃并获」**——把那个人（`w`）和证据（`p w` 的证明）一起交出去。

三个例子（原文原例，**逐字**）：

```lean
section intro_examples
example : ∃ x : Nat, x > 0 :=
  have h : 1 > 0 := Nat.zero_lt_succ 0
  Exists.intro 1 h

example (x : Nat) (h : x > 0) : ∃ y, y < x :=
  Exists.intro 0 h

example (x y z : Nat) (hxy : x < y) (hyz : y < z) : ∃ w, x < w ∧ w < z :=
  Exists.intro y (And.intro hxy hyz)
end intro_examples
```

- 第 1 个：见证 `1`，证明 `Nat.zero_lt_succ 0 : 1 > 0`；
- 第 2 个：目标是 `∃ y, y < x`——见证取 `0`，而手上的 `h : x > 0` 与 `0 < x` **是同一句话的两个写法**（`>` 是 `<` 的翻转记法，**04-1 起就在用**）；
- 第 3 个：见证 `y`，证明是 `And.intro hxy hyz : x < y ∧ y < z` ✓。

## §3 更省事的写法：`⟨t, h⟩`

原文接着说：

> 当**类型从上下文看得出**时，可以用**匿名构造子** `⟨t, h⟩` 代替 `Exists.intro t h`。

同一个例子，换成 `⟨⟩`（原文原例，**逐字**）：

```lean
section anon_examples
example : ∃ x : Nat, x > 0 :=
  have h : 1 > 0 := Nat.zero_lt_succ 0
  ⟨1, h⟩

example (x : Nat) (h : x > 0) : ∃ y, y < x :=
  ⟨0, h⟩

example (x y z : Nat) (hxy : x < y) (hyz : y < z) : ∃ w, x < w ∧ w < z :=
  ⟨y, hxy, hyz⟩
end anon_examples
```

> ⚠️ 注意第 3 个：**它只写了两个东西在 `⟨⟩` 外面**（`y` 和 `hxy`），可 `hyz` 也在里面——`⟨y, hxy, hyz⟩`。
> 这就是下一节要讲的**套娃**。

---

## §4 ⭐ 套娃：`⟨y, hxy, hyz⟩` 为什么能写三个

关键：`And`（也就是 `∧`）**也是用匿名构造子写的**。

`⟨y, hxy, hyz⟩` 只是**两个**「套起来」的匿名构造子，Lean 从右往左套：

```
⟨y, hxy, hyz⟩   ≡   ⟨y, ⟨hxy, hyz⟩⟩
                      ↑       ↑
                   见证 y   p y 的证明（它自己又是一个 ∧！）
```

对照一下就清楚了（**两个都实跑过，都通过**）：

```lean
section nest
-- 显式版：一环一环写清楚
example (x y z : Nat) (hxy : x < y) (hyz : y < z) : ∃ w, x < w ∧ w < z :=
  Exists.intro y (And.intro hxy hyz)

-- 套娃版：同一件事，交给 `⟨⟩` 自己去套
example (x y z : Nat) (hxy : x < y) (hyz : y < z) : ∃ w, x < w ∧ w < z :=
  ⟨y, hxy, hyz⟩
end nest
```

**什么时候能省？** 当 Lean **从目标看得出**「这一层应该是 `∧`」的时候。
本课的目标形状固定是 `∃ …… , …… ∧ ……`，所以省得掉；换成别的形状就不一定了——**拿不准就写显式版**（§6 那张表）。

## §5 ⭐ 本课最容易出事的地方：`p` 得靠**推**

回头看 §2 那张表：`Exists.intro` 的**谓词 `p` 是隐式的**——你没写它，Lean 得**自己推出**「你是想说哪个谓词」。

原文专门提醒：

> 这**不是小事**（This is not a trivial affair）。比如有 `hg : g 0 0 = 0`，写 `Exists.intro 0 hg` 时，`p` 有很多种可能——
> `∃ x, g x x = x`、`∃ x, g x 0 = x`、`∃ x, g x x = 0`……**Lean 靠上下文来定**。

拿一个定理试一下（**实跑**，原文的例子换了名字）：

```lean
section infer_p
variable (g : Nat → Nat → Nat)

theorem gex1 (hg : g 0 0 = 0) : ∃ x, g x x = x := ⟨0, hg⟩

set_option pp.explicit true in
#print gex1
end infer_p
```

`set_option pp.explicit true` 是让 Lean **把隐式参数也打出来**。实跑输出（**逐字**）：

```
theorem gex1 : ∀ (g : Nat → Nat → Nat),
  @Eq Nat
      (g (@OfNat.ofNat Nat (nat_lit 0) (instOfNatNat (nat_lit 0)))
        (@OfNat.ofNat Nat (nat_lit 0) (instOfNatNat (nat_lit 0))))
      (@OfNat.ofNat Nat (nat_lit 0) (instOfNatNat (nat_lit 0))) →
    @Exists Nat fun x => @Eq Nat (g x x) x :=
fun g hg => @Exists.intro Nat (fun x => @Eq Nat (g x x) x) (@OfNat.ofNat Nat (nat_lit 0) (instOfNatNat (nat_lit 0))) hg
```

（那一大串 `@OfNat.ofNat Nat (nat_lit 0) (instOfNatNat (nat_lit 0))` **就是 `0`**，只是显式写全了——`0` 落在 `Nat` 上靠的是类型类实例，**第 10 章**会讲，现在当成 `0` 看就行。）

**要看的是这一处**：

```
@Exists.intro Nat (fun x => @Eq Nat (g x x) x) …… hg
                 └────────── 这个 p 是 Lean 推出来的 ──────────┘
```

**它推对了**：`p := fun x => g x x = x`，正好是目标那个谓词。

所以结论是：

> `⟨w, h⟩` 里那个 `h` 的**类型**，必须**恰好**是「目标里的谓词在见证 `w` 处的实例」。
> 你换了见证，`h` 的类型也就跟着换——**这两样必须配套**（题 4 就是考这个）。
