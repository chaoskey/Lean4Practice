> 本课只讲一件事：**Lean 里每个表达式都有类型**，以及三个最常用的工具。

---

## 1. 「类型论」这个名字从哪来

**类型论（type theory）** 之所以叫这个名字，就因为它的一条基本主张：

> **每一个表达式，都有一个关联的类型。**

举个例子感受一下：

- `x + 0` —— 它可能表示一个**自然数**
- `f` —— 它可能表示一个**在自然数上的函数**

在 Lean 里，任何东西都有类型，没有例外。这一条是本课程后面所有内容的地基。

---

## 2. 怎么声明一个新东西：`def`

```
def  m  : Nat  :=  1
│    │    │     │   │
│    │    │     │   └── ④ 它的「值」是 1
│    │    │     └────── ③ `:=` 读作「定义为」
│    │    └──────────── ② 它的「类型」是 Nat
│    └───────────────── ① 给它起名叫 m
└────────────────────── `def`：声明一个新常量的关键字
```

所以 `def m : Nat := 1` 整句读作：

> **声明一个常量叫 `m`，类型是 `Nat`，值是 `1`。**

`def` 是 "define" 的缩写。这个句式你后面会写几千遍。

---

## 3. 问类型：`#check`

`#check` 用来问 Lean：「这个东西是什么类型？」

```lean
#check m        -- m : Nat
```

输出格式和之前一样，**永远是**：

```
表达式 : 类型
```

**`#check` 是你在本课程里最常用的工具。** 不确定任何东西的类型时，直接问它。

---

## 4. 求值：`#eval`

`#eval` 用来问 Lean：「这个东西**算出来等于多少**？」（"eval" = evaluate）

```lean
#eval 5 * 4     -- 20
```

注意输出的区别：**`#eval` 只打印值，不打印类型。**

### 这两个工具有什么不同（本课关键）

| 工具 | 回答的问题 | 输出长什么样 |
|---|---|---|
| `#check` | 它**是什么类型**？ | `m : Nat` |
| `#eval` | 它**等于多少**？ | `20` |

**两个问题完全不同。** 拿 `5 * 4` 举例：

- `#check 5 * 4` 会告诉你它是 `Nat` —— 但**不告诉你等于 20**
- `#eval 5 * 4` 会告诉你 `20` —— 但**不告诉你它是 `Nat`**

---

## 5. 注释

两种写法：

```lean
-- 两个减号：这一行剩下的部分是注释

/- 斜杠星号
   中间可以跨很多行
-/
```

块注释 `/- -/` **可以嵌套**（这在别的语言里很少见）：

```lean
/- 外层
   /- 内层 -/
   外层继续
-/
```

有什么用？——可以放心地把一大块代码「注释掉」，哪怕里面本来就有注释，也不会乱。

---

## 6. 小结

本课记住三件事：

1. **每个表达式都有类型**（类型论的基本主张）
2. **`def` 声明常量**：`def 名字 : 类型 := 值`
3. **两个提问工具**：`#check` 问类型，`#eval` 问值
