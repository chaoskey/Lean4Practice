## §3 三个「怎么下手」的提示

### 3.1 目标是 `↔` 怎么办

`↔` 的构造子是 `Iff.intro`（**03-6 起就用过**）：

```lean
section iff_demo
theorem iff_demo (p q : Prop) : (p ↔ q) ↔ (q ↔ p) :=
  Iff.intro
    (fun h => Iff.intro h.mpr h.mp)
    (fun h => Iff.intro h.mpr h.mp)
end iff_demo
```

**两个方向各是一个 `fun`**：第一个参数证 `→`，第二个证 `←`。

### 3.2 目标是 `∀ x, …` 怎么办

**写 `fun x => …`**（04-1 就学的）。反过来，**手上有一条 `h : ∀ x, …`**，用它的办法是**给它一个具体的 `x`**：`h x`。

### 3.3 手上是 `∨`、要证的是 `∨`

**用 `Or.elim` 分两种情况**（**不是** `byCases`——`byCases` 要判断「哪个是真的」，那是**经典的**；而 `Or.elim` 只是把手上已有的 `∨` 拆开，**构造性**）：

```lean
section or_elim_demo
theorem or_elim_demo (p q r : Prop) (h : p ∨ q) (hp : p → r) (hq : q → r) : r :=
  h.elim hp hq
end or_elim_demo
```

## §4 ⭐ 「**推不出来**」要怎么讲清

原文在第一条分配律后面加了一句：

> 你还应该想清楚，**最后那个例子的反向推不出来**。

这是本课程第一次让你正面回答「**推不出来**」。**03-8 立过的规矩**在这里必须遵守：

> 说「**证不出**」**不能**只凭「我试了没试出来」——那只能说明**我的写法不行**。
> 要给**四层证据**：① 目击失败（**弱**）；② `#print axioms`；③ 构造性「最近邻居」；④ **反模型**。

**这里最有力的是第 ④ 层：反例。** 我们那条是

```
(∀ x, p x) ∨ (∀ x, q x)  →  ∀ x, p x ∨ q x        （题 3，推得出来）
∀ x, p x ∨ q x  →  (∀ x, p x) ∨ (∀ x, q x)        （反向，推不出来）
```

**取一个具体的例子**：令 `α := Bool`、`p x := (x = true)`、`q x := (x = false)`。

- **右边** `∀ x, p x ∨ q x`：`Bool` 只有 `true`、`false` **两个值**，两个都满足 ✓
- **左边** `(∀ x, p x) ∨ (∀ x, q x)`：**假** ✗ —— 因为 `∀ x, x = true` 假（`false` 是反例），`∀ x, x = false` 也假（`true` 是反例）

**右边真、左边假** → 所以「右边 ⟹ 左边」**不成立**，反向**推不出来** ✓

**这个反例，关键的那一半机器验证过**：

```lean
section counterexample
theorem not_both (h : (∀ x : Bool, x = true) ∨ (∀ x : Bool, x = false)) : False :=
  h.elim
    (fun h1 => Bool.false_ne_true (h1 false))
    (fun h2 => Bool.false_ne_true (Eq.symm (h2 true)))
end counterexample
```

（⚠️ 诚实交代：另一半——「`Bool` 只有两个值，所以 `∀ x, x = true ∨ x = false` 成立」——**要分类讨论**，而 `match`／`cases` 属**第 7 章**，所以**这一步本课程不做机器验证**，只当**数学事实**用 ✓。这正是 03-8 那四层证据里说的：**哪一层能实测、哪一层只能标「数学事实」，要写清楚**。）

## §5 ⭐ 有一边为什么**必须**用经典

原文第 2 组里有一条：

```
(∀ x, p x ∨ r)  ↔  (∀ x, p x) ∨ r
```

**「←」方向是构造性的**（右边给了一条 `∀ x, p x` 或一条 `r`，两种情况都好办）。
**「→」方向必须用经典**：你要判断那个 `r` **到底成不成立**——**这正需要「`r` 或者非 `r`」**。

经典逻辑本课程在 **03-8～03-10** 讲过了，它的**项**形式是 `Classical.em`：

```
Classical.em (p : Prop) : p ∨ ¬p
```

⚠️ **注意它是「项」不是 tactic**——所以本课仍然不需要 `byContradiction`／`byCases` 那些 tactic。
用法（**限定名，不 `open Classical`**）：

```lean
section classical_direction
theorem classical_direction (α : Type) (p : α → Prop) (r : Prop) :
    (∀ x, p x ∨ r) → (∀ x, p x) ∨ r :=
  fun h => (Classical.em r).elim
    (fun hr => Or.inr hr)
    (fun hnr => Or.inl (fun x => (h x).elim (fun hp => hp) (fun hr => absurd hr hnr)))
end classical_direction
```

### ⭐ 但**真正的重点**在这里：用没用经典，一查就知道

```lean
section axioms_check
theorem constructive_one (p : Prop) : p → ¬¬p := fun hp hnp => hnp hp

theorem classical_one (p : Prop) : ¬¬p → p :=
  fun hnn => (Classical.em p).elim (fun hp => hp) (fun hnp => absurd hnp hnn)

#print axioms constructive_one
#print axioms classical_one
end axioms_check
```

实跑输出（**逐字**）：

```
'constructive_one' does not depend on any axioms
'classical_one' depends on axioms: [propext, Classical.choice, Quot.sound]
```

**读法**：

> 经典**不是「更强的手艺」，是「多给了一条假设」**——那三条公理就是它的**价格**。
> **唯一可靠的判据是 `#print axioms`**（03-8 立下的）；`rfl`、编译通过、打印形状**都判断不了这个**。

**所以**：能用构造性做出来的，**尽量别用经典**——不是因为「不纯」，而是因为**你要知道自己多花了什么**。
