# 第 4 章 · 第 7 课：存在量词 `∃`（二）——**消去**

> **本课范围**：原文 **4.4 The Existential Quantifier** 的**后半**——「拿到一个 `∃` 之后怎么**用它**」。
> 上一课（04-6）讲的是怎么**证出** `∃`；本课讲怎么把它**拆开**。
>
> **本课一句话**：`Exists.elim` 让你把 `∃ x, p x` **拆成**「有一个 `w`，而且有 `p w`」——
> 但**那个 `w` 是私有的，你看不见它是谁**，所以你只能写「**不管它是谁都能成立**」的证明。
>
> ⚠️ **全节 tactic 0 处**：本课**只用证明项**。

---

## §1 为什么「拿到 `h : ∃ x, p x`」还不算拿到东西

先看一个事实：**`h` 是一个命题的证明，不是那个 `x`**。

```lean
#check @Exists.elim
```

实跑输出（**逐字**）：

```
@Exists.elim : ∀ {α : Sort u_1} {p : α → Prop} {b : Prop}, (∃ x, p x) → (∀ (a : α), p a → b) → b
```

（Lean 打印时把那个约束变量叫 `a`，名字随便——下面为了跟 `∃ x` 对上，我写成 `w`。）

逐段读：

| 部分 | 是什么 |
|---|---|
| `(∃ x, p x)` | **你手上那个**「存在」的证明 |
| `(∀ (w : α), p w → b)` | **你要交的**：一个函数，输入「一个 `w`」和「`p w` 的证明」，输出 `b` 的证明 |
| `b` | 你想要的**任意命题**（`{b : Prop}` 是隐式的，由目标推） |

**关键在第二条**：你要交的**不是一个证明，而是一个函数**。

---

## §2 ⭐ 本课最重要的观念：见证是**私有的**

为什么非要交函数？

因为 `h : ∃ x, p x` 只说「**存在**某个满足 `p` 的东西」——**它没告诉你是谁**。
你写代码的那一刻，**不能假设**那个 `x` 是 `0`、是 `1`、或者是你想要的任何具体值。

所以 Lean 要求你写成：

> 「**给我任意一个 `w`，再给我 `p w` 的证明**，我就能做出 `b`」

——这样一来，**不管真实的见证是哪个**，你的证明都成立。

**对照 04-6**（两课合起来看就清楚了）：

| | 你做的事 | 得到什么 |
|---|---|---|
| **构造**（04-6） | 你**交出** 见证 `w` ＋ `p w` 的证明 | 一个 `∃` 的证明 |
| **消去**（本课） | 你**收到**（假想的）见证 `w` ＋ `p w` 的证明 | 你想要的 `b` |

两边**顺序一样**：**先见证、后证明**。（题 4 就是考这个顺序。）

---

## §3 原文的消去例子，逐步拆

原文给的第一个消去例子（**逐字**）：

```lean
section elim_original
variable (α : Type) (p q : α → Prop)

example (h : ∃ x, p x ∧ q x) : ∃ x, q x ∧ p x :=
  Exists.elim h
    (fun w =>
     fun hw : p w ∧ q w =>
     show ∃ x, q x ∧ p x from ⟨w, hw.right, hw.left⟩)
end elim_original
```

一层一层看：

| 部分 | 作用 |
|---|---|
| `Exists.elim h (…)` | 把 `h` 拆开，把拆出来的两样东西**喂给**括号里那个函数 |
| `fun w =>` | 第一样：见证（**名字 `w` 是你自己起的**，随便叫——因为它是私有的一件「假设」） |
| `fun hw : p w ∧ q w =>` | 第二样：`p w ∧ q w` 的证明（这里**必须写类型**，否则 Lean 不知道 `p w` 里的 `w` 是哪个） |
| `show ∃ x, q x ∧ p x from ⟨w, hw.right, hw.left⟩` | 交出结果：**用同一个 `w`** 重新装一个 `∃` |

> 📌 注意最后一行：**拆出来的 `w` 是可以拿出去再用的**——`w` 的名字在 `fun` 的作用域里有效。
> 这就是「消去之后再构造」（题 1、题 3 都是这个套路）。

## §4 ⭐ 收口：把前几课全用上

原文 4.4 末尾给了一个「偶数 ＋ 偶数 ＝ 偶数」的例子。原文是用 `rw` 写的（**第 5 章**），
下面这个版本**只用你已经学过的东西**：04-6 的 `Exists.intro`／`⟨⟩`、本课的 `Exists.elim`、
04-4 的 `congrArg`、04-5 的 `calc`。

```lean
section capstone
variable (a b : Nat)

def IsEven (n : Nat) : Prop := ∃ k, n = 2 * k

theorem even_plus_even (h1 : IsEven a) (h2 : IsEven b) : IsEven (a + b) :=
  Exists.elim h1 (fun w1 (hw1 : a = 2 * w1) =>
  Exists.elim h2 (fun w2 (hw2 : b = 2 * w2) =>
    Exists.intro (w1 + w2)
      (calc a + b
        _ = 2 * w1 + b       := congrArg (fun x => x + b) hw1
        _ = 2 * w1 + 2 * w2  := congrArg (fun y => 2 * w1 + y) hw2
        _ = 2 * (w1 + w2)    := (Nat.mul_add 2 w1 w2).symm)))
end capstone
```

逐段读：

1. **拆第一个**：`h1 : ∃ k, a = 2 * k` → 拿走 `w1` 和 `hw1 : a = 2 * w1`；
2. **拆第二个**：同样拿走 `w2` 和 `hw2 : b = 2 * w2`；
3. **要把 `a + b` 写成 `2 * 某个东西`**——那个东西显然是 `w1 + w2`，所以交见证 `w1 + w2`；
4. 剩下要证的是 `a + b = 2 * (w1 + w2)`，用 `calc` 三步：
   - 把 `a` 换成 `2 * w1`（`congrArg` 只动 `+ b` 这一边）；
   - 把 `b` 换成 `2 * w2`；
   - `2 * w1 + 2 * w2 = 2 * (w1 + w2)` —— **方向是反的**，所以用 `(Nat.mul_add 2 w1 w2).symm`（04-3 的 `.symm`）。

> ✅ 这一条把**第 4 章前面五课的东西全串起来了**：`∃` 的构造与消去、`congrArg`、`calc`、`.symm`。
> 看到这种题，先问自己：**我现在是在「拆」还是在「装」？**

## §5 本课不引入（明确标注）

| 原文里的东西 | 属于哪里 | 现在为什么不必理解 |
|---|---|---|
| `match h with \| ⟨w, hw⟩ => …` | **第 7 章（Inductive Types）** | **模式匹配**。03-4 讲义里就标注过「`match` 属第 7 章」——**本课继续不引入** |
| `match h with \| ⟨w, hpw, hqw⟩ => …`（**直接拆到 `∧` 里面**） | **第 7 章** | 也是模式匹配。它靠的是「`∧` 的构造子也是 `⟨⟩`」（**04-6 讲义 §4** 讲过），但**语法**属于第 7 章 |
| `let ⟨w, hpw, hqw⟩ := h` | **第 7 章** | 带模式的 `let` |
| `fun ⟨w, hpw, hqw⟩ => …` | **第 7 章** | 参数位置写模式 |
| 原文那条 `by rw [...]` 的版本 | **第 5 章** | tactic；本课 §4 给了**证明项版** |
| `open Classical` / `byContradiction` / `byCases` | **经典逻辑**（更后面） | 那几个是经典原理 |
| 原文末尾那批 `↔` 练习（`∃` 与 `∀`／`¬` 的等价） | **04-9（收官）** | 其中好几条**依赖经典逻辑**（排中律那一类） |

> ✅ 本课用的东西：`Exists.elim`、`fun w => fun hw : … => …`、`Exists.intro`／`⟨⟩`、
> 以及前面几课的 `congrArg` / `calc` / `.symm` / `Nat` 表。
> **一句提醒**：`fun w => fun hw : p w => …` 只是**普通的 λ**（03-x 学的 `fun`），**不是模式匹配**——
> 因为 `w` 和 `hw` 都是**普通形参名**，没有人去「拆开」一个构造子。
